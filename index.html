About

I'm a Computer Science student at Asia Pacific University, specializing toward artificial intelligence and data science. Alongside that focus, I'm currently working through R programming, data analysis, and system & network administration coursework, having already completed foundational units in networking, databases, entrepreneurship, AI, mathematics, and system analysis & design.

That mix is intentional. I don't just want to build models — I want to understand the databases they read from, the systems they run on, and the networks that connect them. My hands-on work spans Python, C#, and SQL for building applications, Git and GitHub for version control, Visual Studio as my main IDE, and Figma for UI/UX design work like my fashion e-commerce prototype. I've also worked directly with Cisco Packet Tracer to design and configure a small network from scratch.

I'm still early in this journey — a student building real, working projects rather than someone with years of industry experience — but every project below was designed, built, and debugged by me.
